# Fictional planet artwork

All ten destination textures and the weather-opacity mask were created for Space Race using OpenAI's built-in ImageGen tool, without real-planet reference images. Geography, impact distributions, ice formations and storm arrangements are invented. No Solar System Scope, NASA, Earth or other mapped real-body imagery remains in these active texture files.

The repository retains original lossless sources, exact generation/edit prompts, native dimensions and hashes in `assets/planets/`. Runtime processing prepares seam/pole continuity, cloud alpha and restrained relief/roughness/lava emission. The original source files are the reproducible artwork masters.

The interactive Rogue Moon and asteroid materials are separately authored through the included Blender generator and use original procedural geology.
